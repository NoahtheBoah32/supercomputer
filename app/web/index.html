Step 2 of 2

Add your generation keys

ElevenLabs, Higgsfield or fal for images; PiAPI for video. Add the ones you have and switch image providers per chat. Keys are stored in your user folder with owner-only permissions, handed to the pipeline as environment variables, never shown again and never sent to this page.

Without an image key the pipeline can plan, but image generation will refuse to run. Video (Seedance) renders through PiAPI, or through the ElevenLabs Image & Video API when that is the key you have; the Docs link above explains the PiAPI key.
