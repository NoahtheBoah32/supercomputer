# Compiled Prompts — By Format

A working reference built from the project's own conversation history (141 sessions,
20 Aug – 7 Sep 2026). Every prompt below is a real output that was handed over for
generation, grouped by what it produces. Use these as **format templates** — the
skeleton is what matters; the subject is swappable.

> Scope note: this is a prompt-engineering project. Nothing here was generated by an
> image/video model inside Claude — these are the prompt texts only.

---

## 0. Conventions that hold across every category

| Rule | Detail |
|---|---|
| **Character budget** | positive + negative combined **≤ 1500 chars** for the Seedance/Dreamina default. Character-sheet prompts run to ~2.5k per view / ~3.2k for a tiled sheet and are flagged as over-budget on purpose. |
| **Negative handling** | If the model has a dedicated negative field (Kling, Seedream) → ship a second code block. If it doesn't (Seedance, GPT Image) → fold the avoidances into the positive as a trailing `Avoid: …` / `No …` clause. |
| **Palette** | Either a real hex lock (`red #E4002B`, plus a per-scene sampled set) **or** explicit "descriptive palette language only, no invented hex". Never a made-up number. |
| **Aspect ratio** | Always stated. `16:9` for scenes/video, `4:5 vertical` for portrait views, `3:2 landscape` for tiled sheets. |
| **Locks / Continuity** | Named rigid elements listed after the action ("Locks: …" / "stay rigid and unwarped"). Plus a standing "subject and environment identical across every generation from this reference" line for continuity. |
| **Reference-role scoping** | With multi-image models, each input image is given an explicit job ("Image 1 = base plate, locked; Image 2 = light-element material only, ignore its black background; Image 3 = placement/direction only, not its colour"). |
| **The brand motif** | A red `#E4002B` + white "energy/data light trail" — sometimes a single ribbon, sometimes a braided fiber-optic bundle with white-hot travelling beads — is the recurring hero element and is almost always "the only saturated colour". |

## 8. Negative-prompt patterns (reference field)

Negatives cluster into five buckets — every shipped negative is some mix of these:

1. **Motif discipline** — `no colours outside red #E4002B and white/neutral`,
   `no duplicated or extra light trails`, `no flicker or strobing on the threads`,
   `bundle fragmenting`, `no second vanishing point`.
2. **Rigidity** — `no warping / bending / drift on [named landmarks]`,
   `tilted horizon`, `parallax warping`, `structure pulsing`.
3. **Camera** — `no camera shake / jitter`, `no orbiting or arcing` (when a flat
   move is wanted), `no overshoot`, `no direction change mid-pan`,
   `no motion-interpolation smoothness`.
4. **AI tells** — `CGI or 3D-render look`, `oversharpened digital clarity`,
   `plastic / waxy skin`, `blown-out whites`, `extra fingers / limbs`,
   `warped faces`.
5. **Text** — `no legible text, logos, UI, signage, watermark, gibberish digits`.
