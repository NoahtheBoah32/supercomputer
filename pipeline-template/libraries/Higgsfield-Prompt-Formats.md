# Higgsfield — Prompt-Engineered Formats

A working reference to how Higgsfield AI structures prompts, compiled from Higgsfield's
own docs, blog "full prompt library" pages that accompany its YouTube tutorials, and
community reverse-engineering (Kapwing, Segmind, the "Cannes manual", an OSideMedia
skill repo). Research date: **Sep 2026**.

> Scope note: this is a prompt-engineering reference. Nothing here was generated by an
> image/video model — these are prompt texts and templates only. Higgsfield is a
> **weak model to mine for camera-move text** (its camera language lives in the model
> weights and a preset menu, not the prompt); the value is in its **multi-shot
> Cinema Studio / Seedance markup** and its scene-description conventions.

Reliability tags used throughout: **[OFFICIAL]** = Higgsfield docs or Higgsfield's own
prompt dumps · **[COMMUNITY]** = practitioner reverse-engineering · **[SEO]** =
low-trust AI-generated guide, pattern only.

---

## 0. The two prompt paths

Higgsfield has **two distinct prompting models**, and they follow different rules:

| Path | What it is | Prompt job | Syntax |
|---|---|---|---|
| **DoP preset path** | The simple image-to-video flow: upload keyframe → pick 1 of 100+ camera presets → short scene line → generate 3 or 5 s | Scene content only. Camera move = the preset, not text. | **No markup.** Plain prose. Optional "Enhance". |
| **Cinema Studio / Seedance multi-shot path** | Multi-shot films, ads, POVs | A full shot-by-shot brief with reference tags, per-cut FOV, style header, locks | **Substantial markup** — `@tags`, `<<<image_n>>>`, degree-FOV, timed beats, positive locks |

Everything below is organised by that split.

---

## 1. DoP preset path — the scene line

### 1.1 Composition pattern  [COMMUNITY consensus + OFFICIAL hints]

```
[optional: name the camera move again in text]  +
[subject: who/what, wardrobe, expression]  +
[one action]  +
[setting]  +
[lighting: source + direction]  +
[lens / DoF]  +
[mood]
```

- **One camera move + one subject action per clip.** Never stack moves. (Higgsfield's
  Sora 2 and Seedance guides both state this. [OFFICIAL])
- The preset does **not** replace the prompt — you always write a scene line too.
- Naming the move in the text *and* selecting the matching preset gives the most
  repeatable result. [COMMUNITY]
- Higgsfield's model "responds to cinematographic language, not narrative
  description — tell it how the scene looks, not what it means." [COMMUNITY, Segmind]

### 1.2 The I2V identity-hold clause  [COMMUNITY, widely repeated]

When using DoP / Image-to-Video on an existing still, append:

```
preserve the original face, lighting, and geometry
```

Tells the engine to apply the camera move without redrawing the subject.

### 1.3 "Enhance" behaviour  [OFFICIAL + COMMUNITY]

- A toggle. Auto-expands a terse line into a lighting-and-mood paragraph "with details
  relevant to the selected motion type."
- Example of what it does — input is a one-liner, output is:
  > "In a serene mountainous landscape, the sun prepares to set, casting soft pastel
  > hues across the sky. A content man effortlessly cradles his large brown Labrador
  > retriever…"
- Caution: Enhance overrides deliberate minimalism and can drift style. Turn off when
  you have a tight brief.

### 1.4 Preset catalogue (verbatim names, [OFFICIAL](https://higgsfield.ai/camera-controls))

The **injected text for each preset is not exposed** — presets condition a trained
model, they are not text macros. Only the effect is documented.

- **Basic:** General, Static, Zoom In/Out, Pan Left/Right, Tilt Up/Down, Dolly In/Out/Left/Right, Arc Left/Right, Crane Up/Down, Jib Up/Down, Overhead, Incline
- **Epic / signature:** Super Dolly In/Out, Double Dolly, Dolly Zoom In/Out, Crash Zoom In/Out, Rapid Zoom In/Out, YoYo Zoom, 360 Orbit, Lazy Susan, 3D Rotation, Crane Over The Head, Robo Arm, Whip Pan, Aerial Pullback, FPV Drone, Flying Cam Transition, Through Object In/Out
- **Effects / stylized:** Bullet Time, Snorricam, Dutch Angle, Fisheye, Handheld, Low Shutter, Wiggle, Focus Change, Object POV, Hero Cam, Eyes In, Mouth In, Eating Zoom, Glam, BTS, Head Tracking
- **Vehicle:** Car Chasing, Car Grip, Road Rush, Buckle Up
- **Time:** Hyperlapse, Timelapse Landscape / Human / Glam
- **Mix** = UI option to blend presets into one move

UI categories in the picker: Effects · Basic Camera Control · Epic Camera Control ·
Catch the Pulse · New · Trending · Mix.

Named in some briefs but **not** on the current list: "Explode", "Face Punch"
(renamed/deprecated or from a competitor).

### 1.5 Behaviour notes worth keeping

| Preset | Note |
|---|---|
| **Crash Zoom In/Out** | One violent beat per clip; overuse kills the punch |
| **Bullet Time** | Time freezes, camera sweeps 180–360° around a frozen subject; sell it with suspended particulate (dust, droplets) + backlight |
| **Dolly Zoom In/Out** | Vertigo — background warps while subject holds |
| **360 Orbit / Lazy Susan / 3D Rotation** | Product "in the round"; pair with macro lens + rim light |
| **Robo Arm** | Fast, precise, complex motion-control-rig path |
| **FPV Drone** | Low, fast, weaving, then climb to reveal |
| **Through Object In/Out** | Camera passes through glass / foliage / keyhole |
| **Snorricam** | Subject fixed in frame, world moves around them |

## 2. Cinema Studio / Seedance multi-shot path — the markup

> **See also [Seedance-Prompt-Architecture.md](Seedance-Prompt-Architecture.md)** — the
> block-level architecture, sourced from Higgsfield's own shipped `seedance-clean` skill.
> It supersedes this section for Seedance specifically (block order, FOV anchor table,
> timing scale, special protocols). This section remains the token/preset catalogue.

This is where Higgsfield has a real prompt syntax. All tags below are **[OFFICIAL]** —
lifted from Higgsfield's own blog prompt dumps for its YouTube tutorials.

### 2.1 Reference & element tags

| Token | Meaning | Example |
|---|---|---|
| `@name` | Element tag — must match **exactly** an asset registered in Higgsfield's **Elements** panel. Used for characters *and* locations/props. | `@Orlando`, `@Maria`, `@hero`, `@headphones`, `@eduardo`, `@loc_cabin`, `@map_prop`, `@Adil-Cop`, `@Locker-Room` |
| `<<<image_1>>>` / `Image 1` / `reference character image` | Inline pointer to an attached reference image inside the prompt body | `Shot 1: Close-up on <<<image_1>>>` |
| `100% matches` / `POSITIVE LOCKS` | Explicit consistency-lock clause listed per active reference | `@eduardo — 100% matches, face and wardrobe locked` |

> The real "character token" is **`@name` matched to the Elements panel**. The
> `[HERO_ELENA]`-style bracket token from some SEO guides is **not** Higgsfield syntax.

### 2.2 Camera & cut control

| Token / phrase | Effect |
|---|---|
| `Static camera.` | Literal terminal instruction, repeated verbatim across shots |
| `Shot 1:` / `Scene 1.` / `[0–2s]` | Shot / beat numbering |
| `FOV 47°` … (per cut) | Field-of-view in **degrees locked per cut** — e.g. `47°, 29°, 63°, 84°` |
| `Cuts only at the specified points` / `no auto-cuts` | Disables the engine's automatic cutting |
| `No cuts, no zoom, natural head movement` | The Seedance **POV lock** [OFFICIAL] |

### 2.3 The 10-block Cinema Studio prompt template  [OFFICIAL, [case4k](https://higgsfield.ai/blog/case4k)]

```
1.  SCENE CONTEXT
2.  ACTIVE REFERENCES        — @tags + "100% matches" locks
3.  LOCATION MAP
4.  FIRST FRAME / BLOCKING
5.  FORMAT MODE               — aspect ratio + resolution (21:9 Cinemascope, 4K)
6.  CUT-BY-CUT                — one line per cut, FOV in degrees
7.  OPTICS · CAMERA · ACTION · PERFORMANCE
8.  PHYSICS · LIGHTING · AUDIO
9.  STYLE
10. POSITIVE LOCKS           — detailed per-element consistency rules
```

### 2.4 The style-header block  [OFFICIAL, [cinematic_headphones](https://higgsfield.ai/blog/cinematic_headphones)] — **legacy**

> ⚠️ Superseded. Higgsfield's current `seedance-clean` skill explicitly rejects a
> style-prefix block at the top of the prompt and distributes each style aspect into the
> block that governs it — see
> [Seedance-Prompt-Architecture.md §2.1](Seedance-Prompt-Architecture.md). Keep this
> header only for a quick ad where every shot shares one look; it is wrong wherever light
> or lens changes shot to shot.

One labelled line each, prepended to every shot in an ad:

```
Format:      8K IMAX commercial, 16:9 widescreen. Photorealistic — no 3D render, no game engine.
Lighting:    Natural light only [+ per-scene direction]
Camera:      Physical cine lens. 180° shutter motion blur
Skin:        Pore-level realism — vellus hair, asymmetric moles, capillary flush
Acting:      Hollywood — micro-pauses before reactions, precise eye-line, living eyes
Physics:     Gravity and inertia respected — mass has real weight, correct contact shadows
Composition: Rule of thirds + golden ratio. Every person moving from frame one
Technical:   24fps smooth motion. 8K detail. No jitter
Audio:       Diegetic dialogue and environmental SFX only. No music. No subtitles
Color grade: 60:30:10 — dominant / secondary / accent
Continuity:  Characters, props, environment identical across every cut. No identity drift
```

### 2.5 Seedance 2.0 universal rules  [OFFICIAL, [seedance-prompting-guide](https://higgsfield.ai/blog/seedance-prompting-guide)]

- **Open the prompt with: number of shots · total duration · aspect ratio.**
- Standard technical opener (verbatim):
  ```
  Montage, multi-shot action Hollywood movie, don't use one camera angle or single cut, cinematic lighting, photorealistic, 35mm film quality, professional color grading, ARRI ALEXA aesthetic
  ```
- Realism forcing (verbatim): `no 3D, no cartoon, no VFX`
- POV lock (verbatim): `No cuts, no zoom, natural head movement`
- Inline VFX cue (verbatim, the **only** officially sanctioned bracket syntax):
  ```
  [VFX: branching electric circuits pulsing with white-blue current]
  ```
- Five prompt "formats": Transformations · Orbs · POVs · Fights · Animation
  (0–3 s / 3–6 s timed segments).

### 2.6 Seedance 2.5 "omni-reference" roles  [COMMUNITY, [OSideMedia skill](https://github.com/OSideMedia/higgsfield-ai-prompt-skill) — one practitioner's reverse-engineering, not confirmed]

- Modes: `t2v` / `omni_reference` / `video_edit` / `video_extension`
- Reference roles: `@Image` / `@Video` / `@Audio`
- Asset cues: `[music: type]` · `[sfx: effect]` · `[dialogue: …]` · `[subtitle: …]`

**Now partly confirmed [OFFICIAL].** Higgsfield's 2.5 guide documents the capability
envelope behind these roles: up to **50 multimodal references** per generation (30 image,
10 video, 10 audio), clips to **30 s**, any ratio **9:16 → 21:9**, native audio in the same
pass, and region edit. The mode *names* above remain community reverse-engineering; the
reference-role split and the ceilings do not. Full detail and the tested findings:
[Seedance-Prompt-Architecture.md §9](Seedance-Prompt-Architecture.md).

### 2.7 Dialogue & performance conventions

- **Dedicated Dialogue block** per shot. [OFFICIAL, Sora 2 guide]
- Speaker line form: `@Name with a slight smirk says: "…". Static camera.` [OFFICIAL]
- **Anatomical acting direction over emotion labels** [COMMUNITY, [Cannes manual](https://higgesfieldcannesmanual.netlify.app/)]:
  don't write "he's sad" → write
  ```
  jaw tight, eyes fixed on the closing gap, fingers hyperextended, knuckles white
  ```
- Phonetic stress for dialogue: hyphens + caps — `Gan-del-FEE-nah`
- `"Cinematic" is meaningless` → give a camera setup: `anamorphic prime, f2.8, organic grain, halation on highlights`
- Position everything relative to **one fixed anchor object** in frame.

## 3. Soul / Soul ID — image-model prompting  [OFFICIAL]

### 3.1 Options

| Setting | Values |
|---|---|
| Quality | `1.5k` or `2k` |
| Aspect ratios | 9:16, 3:4, 2:3, 1:1, 4:3, 16:9, 3:2 |
| Batch | 1–4 images |
| Reference image | Attaching one **disables the text prompt field**; drive style from image + preset / Soul ID / Soul HEX |
| Stack (no ref image) | prompt + Preset **or** Moodboard + Soul ID + Soul HEX |

### 3.2 Prompt convention

**Short wins.** Prompts under ~100 words; the presets and model carry the taste.
Official short-prompt examples:

```
editorial street style, neon Tokyo alley
coquette portrait in retro BW
Y2K band promo shot
```

No weighting syntax, no negative field for Soul.

### 3.3 Named style presets (50+; verbatim sample)

General · Warm Ambient · Subtle Flash · Theatrical Light · Flash Editorial ·
Editorial Street Style · Street Photography · Mystique City · Candy Pop · Siren ·
Swag Era · Y2K Studio · Y2K Street · Retro BW · Digital Camera · Asian Nostalgia ·
Surreal Solarization · 2000s Band · Frutiger Aero · Drain · Old Smartphone · Old Money

Picker categories: General · TikTok Core · Instagram Aesthetics · Beauty · Mood ·
Camera Photo · Graphic Art.

### 3.4 Moodboard (Soul 2.0)

Upload **20+ cohesive, face-free** images → model derives lighting, texture, contrast,
colour into a reusable style.

### 3.5 Soul HEX palettes

Film colors · Lime Jam · Candy pink · Nostalgic blue · Soft palette · Black gloss
(Soul 2.0 / Soul Cinema only).

### 3.6 Soul ID (identity training)

| Item | Spec |
|---|---|
| Training set | **min 20 photos** of one person; varied angles/expressions, well-lit, no sunglasses/heavy shadow, ≥1 full-height, ideally shot in the last 4–5 months |
| Training time | ~3–5 min |
| Model-locked | A Soul ID trained for Soul 2.0 runs only in Soul 2.0 — separate trains per model |
| After training | Select the character in the **Character tab**, then **choose a style preset**. Official: *"Presets beat freehand prompting here."* Light prompt tweaks allowed, undocumented. |

> **Fabricated by SEO guides, do not use:** `[HERO_ELENA]` token syntax, "3–5 anchor
> images", "lock facial features to 100%" slider, "98.4% identity preservation".

### 3.7 Character-sheet anti-drift trick  [OFFICIAL, case4k]

When building a 3-view reference sheet that will drive video:

```
Erase the face from the full-body shot on the first panel
```

Stops face drift. (This matches this project's own [[character-sheet-format]] note.)

## 4. Parameters & syntax — quick table

| Parameter | Status |
|---|---|
| **Aspect ratio** | UI control, not typed, for DoP (historically inherited from the reference image). For the multi-shot path, **written into the prompt**: `16:9 widescreen`, `21:9 (Cinemascope)`, `2.39:1 Cinemascope`. |
| **Negative prompt** | **No dedicated field anywhere in the Higgsfield UI.** Write negatives inline as positive constraints (`locked-off static camera`, `sharp focus throughout`) or plain `no X` (`No music`, `no brand logos`, `no on-screen text`, `no 3D render, no game engine`). The one blessed idiom: `no 3D, no cartoon, no VFX`. Cinema Studio 3.0 does **not** parse "no blur" / "avoid shaky camera". |
| **Motion strength / intensity** | **Not exposed.** Controlled by preset choice (Rapid vs Crash vs Super Dolly) and verbs. `motion_bucket_id: 127` seen in SEO guides is a Stable Video Diffusion param, **not** Higgsfield. |
| **Seed** | **Yes** — Advanced Settings, all users. |
| **Steps** | **Yes** — Advanced Settings (DoP / Seedance). |
| **Duration** | **3 or 5 s** for DoP presets. Longer on hosted engines (Seedance 2.5 ~30 s, Cinema Studio 3.0 ~15 s — SEO figures). |
| **Enhance** | Toggle; auto-expands terse → paragraph. Off for tight briefs. |
| **Start / end frame** | Start = the uploaded keyframe (DoP is I2V-first). An end-frame field existed in the May 2025 build; absent from current DoP help — 2026 status unconfirmed. |
| **Flag micro-syntax** (`--ar`, `::` weights) | **None.** Higgsfield has never gone the Midjourney route. Only bracket syntax with sourcing: official `[VFX: …]`; community-inferred `@Image/@Video/@Audio` + `[music:]/[sfx:]` roles. |

## 5. Established → new: how the practice shifted

| | **2025 — launch era** | **2026 — aggregator era** |
|---|---|---|
| Core model | DoP-centric. "You don't prompt the camera, you pick it." | Front-end over Seedance / Sora / Kling / Veo + multi-shot Cinema Studio |
| Prompt shape | One short scene line + one preset | **Layered brief**: keyframe/style job + identity job + shot-numbered motion/audio script |
| Text-side rules | Minimal | Declare shots/duration/AR up front · one move + one action per beat · dedicated Dialogue & Audio blocks · inline `[VFX: …]` · anatomical acting direction |
| Camera-side | Preset menu | *More* menu-driven — Cinema Studio 3.5's Genre/Style/Camera pills, 9-item movesets |
| Image | SOUL launch presets (meme-y: "iPhone flash", "Dune-core") | Soul 2.0 + Soul ID push toward 50+ tuned presets + Moodboards, explicitly *away* from freehand |
| Params | duration 3/5 s, seed, enhance, optional end-frame; no negative field, no motion slider | **unchanged** — still no negative field, still no motion slider |

**Net shift:** from "one short prompt + one preset" to "a layered brief", with Higgsfield
absorbing craft decisions into UI controls rather than prompt tokens. No weighting or
flag micro-syntax at any point.

## 7. What's portable to the Neutra DC Seedance/Kling pipeline

- **One camera move + one subject action per shot/beat** (official, repeated everywhere).
- **Shots / duration / aspect ratio declared at the top** of a multi-shot prompt.
- **Anatomical acting direction** instead of emotion labels.
- The **`preserve the original face, lighting, and geometry`** I2V-stability clause.
- Inline **`[VFX: …]`** bracket cues to isolate effects from subject description.
- **Negatives as positive constraints**, plus the realism idiom `no 3D, no cartoon, no VFX`.
- **`Erase the face from the full-body panel`** for character sheets — already in this project's practice.
- Naming the **camera format's flaws** (`cheap wide-angle lens distortion, mild compression artifacts, low dynamic range`) to get its look.

**Not portable / not real:** `(Preset: … · 9:16 · 5s)` trailing tags · `[HERO_ELENA]`
tokens · `motion_bucket_id` · Subject-Lock/Radius/Speed sliders · "98.4% identity".
